# InkLab

Локальная Android-лаборатория рукописных конспектов и OCR, ориентированная на планшет и стилус.

## Что уже работает

- Векторное письмо с сохранением pressure и сглаживанием редких событий стилуса.
- Независимое поведение S Pen, боковой кнопки и пальца; кнопка стилуса временно включает ластик.
- Палец всегда работает как указатель: тап выбирает объект, свайп двигает холст, два пальца масштабируют.
- Короткое касание двумя пальцами отменяет последнее действие.
- Пиксельный ластик, который разрезает штрих, и быстрый ластик целых штрихов.
- Контекстное меню появляется рядом с объектом и содержит распознавание, редактирование, дублирование, удаление и возврат в рукопись.
- Undo/redo на уровне операций.
- Доски и многостраничные тетради, автосохранение, ориентация листа и четыре вида бумаги.
- Быстрые настройки фона и цвета листа прямо в редакторе, палитра пера, светлая и тёмная темы.
- Автовыравнивание линий, окружностей и прямоугольников.
- Подходящий локальный движок выбирается автоматически для текста и формул.
- Русский рукописный текст через Google ML Kit Digital Ink (`ru`), локально после загрузки модели.
- Формулы в LaTeX через Pix2Text MFR и ONNX Runtime Android; SDK и веса уже находятся в APK.
- Проверка размера и SHA-256 перед первым локальным развёртыванием встроенных весов.

## Управление

- Выберите перо, ластик или лассо в плавающей панели слева.
- Повторное нажатие по активному инструменту открывает его параметры.
- Кончик S Pen использует выбранный инструмент; боковая кнопка по умолчанию временно включает ластик.
- Обратная сторона совместимого стилуса всегда работает как ластик.
- Свайп пальцем двигает холст; жест двумя пальцами меняет масштаб.
- Обведите рукопись лассо или коснитесь её пальцем, затем выберите **Распознать → Текст/Формула**.
- Результат сразу заменит рукопись на месте; текст и LaTeX можно редактировать, а исходные штрихи — восстановить.

## Локальные модели

| Движок | Назначение | Доставка | После установки |
|---|---|---|---|
| Google Digital Ink | русский рукописный текст | SDK в APK, языковая модель загружается ML Kit | offline |
| Pix2Text MFR int8 | изображение формулы → LaTeX | SDK и 31.1 МБ весов в APK | offline |

Pix2Text взят из закреплённого commit источника. Gradle получает три файла при сборке, проверяет размер и SHA-256 и упаковывает их в `assets`. При первом использовании приложение копирует их во внутреннее хранилище с повторной проверкой. В готовом APK сеть для распознавания формул не нужна.

MyScript нельзя легально публиковать вместе с открытым репозиторием без выданного разработчику пакета и лицензии. Поэтому незапускаемые заглушки MyScript убраны из списка движков; инструкция для будущей частной интеграции остаётся в `integrations/MYSCRIPT.md`.

## Сборка

Требуются Android Studio/Android SDK 36, JDK 17+ и интернет для первого разрешения Gradle-зависимостей.

```bash
./gradlew testDebugUnitTest assembleDebug
```

Gradle wrapper JAR включён в репозиторий. Минимальная версия Android — API 24 из-за ONNX Runtime Android.
Сборка ограничена `arm64-v8a`, чтобы не раздувать APK несколькими копиями нативного ONNX Runtime; это соответствует современным Android-планшетам.

## Структура

```text
core/ink/               геометрия лассо и ластика
core/model/             штрихи, доски и параметры бумаги
core/models/            каталог и безопасная загрузка весов
core/storage/           локальное хранение досок и настроек ввода
core/recognition/       контракты и реестр движков
recognition/mlkit/      русский Digital Ink
recognition/onnx/       Pix2Text Formula → LaTeX
ui/screens/             редактор, файлы, параметры и настройки
```

Сторонние компоненты и происхождение весов перечислены в `THIRD_PARTY_NOTICES.md`.
