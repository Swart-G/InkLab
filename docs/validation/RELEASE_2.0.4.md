# Release validation — 2.0.4 preview

Дата: 10 сентября 2026.

## Область релиза

- согласованный preview/commit для автокоррекции фигур;
- инерционное листание;
- свойства текста и LaTeX;
- выбор папки из карточки документа;
- живой рендер импортированных PDF/image-фонов;
- подписанные обновления с SHA-256;
- явный переносимый backup для больших данных.

## Автоматические ворота

Перед публикацией выполняются чистые `testDebugUnitTest`, `lintDebug` и `assembleRelease`, затем APK проверяется `apksigner` и публикуется вместе с SHA-256.

## Ограничения

- требуется аппаратная проверка удержания фигур, инерции и S Pen на целевом Galaxy Tab;
- системный Auto Backup ограничен платформой и не заменяет переносимый архив для больших данных;
- production Google OAuth и двухустройственная cloud-приёмка отложены.
